This repo contains the raw data and code used to produce the figures in the manuscript

## Increased avidity of antibodies to V2 mediating ADCC in macaques boosted with recombinant ALVAC rather than DNA Vaccine
Schifanella, Stamos, Goldfarbmuren, Bissa et al. 2026 Plos Pathogens

- raw datasets used can be found in input_data/ccrvb15_olinkALVACALFQA_KCG_list_of_RAW_datasets.xlsx

- analyte names by category can be found in input_data/ccrvb15_olinkALVACALFQA_KCG_list_of_vars.xlsx

- data plotted in each figure panel can be found in outputs/ccrvb15_olinkALVACALFQA_KCG_list_of_plotted.xlsx

- statistical analysis results can be found in outputs/ccrvb15_olinkALVACALFQA_KCG_list_of_stats.xlsx

- formatted supplementary tables with min, max, mean, median and standard deviation can be found in outputs/ccrvb15_olinkALVACALFQA_KCG_suppTables.xlsx

- all code can be found in ccrvb15_olinkALVACALFQA_ForMSv2_KCG.Rmd

- the fully rendered report with a tab for each figure panel can be found in outputs/ccrvb15_olinkALVACALFQA_ForMSv2_KCG.html
